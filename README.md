# daily

这是一个用于学习、实验和小项目积累的仓库。

## 目录约定

- `projects/`：真正可运行的项目或 demo。
- `playground/`：临时实验代码、片段、验证脚本。
- `docs/`：学习笔记、决策记录、环境说明。
- `shared/`：可复用脚本与模板。
- `assets/`：图片、数据等资源文件。
- `archive/`：阶段性封存或不再维护的内容。

## 使用规则

1. 能独立运行的内容放到 `projects/<name>/`。
2. 临时尝试和草稿放到 `playground/`。
3. 每个 `projects/*` 子项目都应有自己的 `README.md`。
4. 超过一段时间不再维护的内容移到 `archive/<year>/`。
